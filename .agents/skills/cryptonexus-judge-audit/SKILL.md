# cryptonexus-judge-audit

## Purpose
Audit CryptoNexus from an adversarial reviewer/judge perspective. (AUDIT ONLY - no automatic modifications).

## Audit Checklist
- alert → raw evidence traceability
- provenance
- heuristic visibility
- IP/ownership distinction
- ML explanation quality
- synthetic metric labeling
- malformed input behavior
- duplicate TXID behavior
- missing-field behavior
- missing GeoIP/model artifact behavior
- offline operation
- runtime external calls
- misleading graph semantics
- unexplained scores
- reproducibility

## Reporting
Report findings by severity: CRITICAL, HIGH, MEDIUM, LOW, INFO.
Do not produce an overall project score.
