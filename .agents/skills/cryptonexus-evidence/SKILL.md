# cryptonexus-evidence

## Purpose
Guarantee provenance.

## Required Chain
ALERT → REASON → FEATURE → COMPUTATION → ENTITY / TRANSACTION / IP → RAW SOURCE RECORD

## Preserved Provenance
- source file
- row/record
- TXID
- timestamp
- original value
- derived value
- transformation
- model version

## Rules
SHAP factors must be translated into understandable investigative explanations.
