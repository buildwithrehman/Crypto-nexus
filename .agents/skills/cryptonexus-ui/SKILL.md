# cryptonexus-ui

## Purpose
Enforce investigation-first UI principles.

## Primary Questions
1. Where should I look first?
2. Why was it flagged?
3. Show me the evidence.

## Priority Screens
Overview, Alert Ranking, Entity Profile, Graph View, Timeline, Evidence.

## Semantic Badges
Observed, Derived, Heuristic, ML-derived, Enriched, Unresolved.

## Avoid
Giant unexplained AI scores, 3D graphs, unnecessary animation, raw SHAP numbers without explanation, decorative charts over evidence, visuals implying IP ownership.

(Design.md remains authoritative).
