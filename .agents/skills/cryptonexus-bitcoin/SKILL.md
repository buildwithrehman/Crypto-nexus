# cryptonexus-bitcoin

## Purpose
Protect Bitcoin-domain semantics.

## Mandatory Distinctions
- Address ≠ wallet ≠ entity
- IP association ≠ ownership
- Network observation ≠ transaction origin
- GeoIP ≠ identity
- Country ≠ person location
- Anomaly ≠ crime
- Suspicion signal ≠ proof of crime
- Confidence ≠ probability of crime
- CIH and change-address detection are heuristics.

## Language Rules
Use: "observed peer", "network association", "common-control hypothesis", "behavioral pattern consistent with...", "requires further investigation".

Never use: "criminal wallet", "confirmed laundering", "IP belongs to criminal", "probability of crime".
